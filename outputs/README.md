# Reproducible Outputs

Store generated proof artifacts here after running the project commands.

Recommended files:

- `test_results.txt` for the Hardhat test output.
- `compile_result.txt` for the Hardhat compile output.
- `deployment_result.txt` for the local deployment address and demo property.
- `frontend_validation.txt` for the manual MetaMask lookup result.

These outputs should contain synthetic addresses and local-chain results only.
